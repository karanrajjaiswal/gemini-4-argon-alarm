# Brahma Alarmy — Standalone Android APK Project

Combines **Alarmy's Mission-Based Wake-Up System** (Math, Shake, Mindful Mantra Typing) with an automatic **Solar-Synced Brahma Muhurta Calculator** (96 minutes prior to daily local sunrise based on GPS coordinates).

## How to Build the APK on GitHub Actions (No Android Studio Needed)

1. Extract this ZIP file on your computer or phone.
2. Create a new repository on [GitHub](https://github.com/new).
3. Upload all extracted files/folders (`.github`, `app`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `README.md`) to the root of your repository.
   - *Tip:* Make sure the `.github/workflows/build-apk.yml` file is included (enable "Show hidden files" if dragging and dropping `.github` via browser, or push via Git CLI).
4. Go to the **Actions** tab in your GitHub repository.
5. Wait ~2 minutes for the **Build Standalone Brahma Alarmy APK** workflow to turn green.
6. Scroll down to **Artifacts** and download **`Brahma-Alarmy-Standalone-APK`**.
